# 3.2.1 Comprehensible description of manufacturing

Copy into Technical Documentation §3.2.1.

---

## Overview

The Achilles Tendon Rupture Night Splint is manufactured as a non-sterile Class I orthosis. Thetis Medical Ltd is the legal manufacturer and controls design, specifications, release and post-market obligations. Production is outsourced to qualified subcontractors under purchase orders, approved drawings/BOM and incoming/final inspection (see §3.3 and §3.4).

No adhesives, solvents, coatings or chemical bonding agents are used. Soft goods are attached by industrial sewing only.

## Process flow

```
1. Shell moulding (RP Technologies)
        ↓
2. Soft goods & assembly (MPD)
        ↓
3. Incoming / final inspection & release (Thetis Medical Ltd)
        ↓
4. IFU print (Hello Print) + carton print (Packhelp)
        ↓
5. Packing, labelling, lot record, ship
```

## Step-by-step description

### 1. Injection moulding — polypropylene shell (RP Technologies)

- Shells are injection-moulded in medical-grade polypropylene to approved CAD/drawings.
- Four moulded variants: Right Small, Right Large, Left Small, Left Large.
- Shells include anatomical curvature for plantarflexion position, sewing edge (tapered), strap guide features, and debossed **L** or **R**.
- Process: injection moulding with self-finishing / self-colouring as specified; no secondary chemical treatment of the shell.
- Traceability: moulding lot / batch identity retained by supplier and/or recorded on receipt by Thetis Medical Ltd.

### 2. Soft goods manufacture and sewing assembly (MPD)

MPD supplies and/or processes textile components and performs sewing/assembly to the approved BOM and golden sample:

| Component | Work |
| ----------- | ------ |
| EVA foam padding | Cut/prepared and sewn to the ventral face of the shell |
| Leg strap | Elastic with silicone grip and hook-and-loop; fixed to shell |
| Foot strap | Elastic with silicone grip and hook-and-loop; fixed to shell |
| Ankle strap | Fabric/elastic with heel aperture; removable via hook patch on shell |
| Hook patch | Fixed to shell to allow removable ankle strap |

Assembly is mechanical (sewing) only. Left/right and size must match the shell variant.

### 3. Inspection and batch release (Thetis Medical Ltd)

Per §3.3:

- Incoming checks on shells, soft goods and print items  
- In-process / assembly checks (stitch integrity, strap function, completeness)  
- Final release against acceptance criteria (completeness, variant, function, appearance, IFU, traceability)  

Non-conforming product is quarantined. Only released lots may be packed for sale.

### 4. Packaging and information for use

- **IFU:** printed by Hello Print from the controlled multi-language master; correct version included in each carton.  
- **Primary pack:** printed carton by Packhelp; artwork includes device identity, manufacturer details and UDI as approved.  
- Each unit is packed as a complete kit: assembled splint + IFU in labelled carton.

### 5. Distribution records

Distribution / sales records are maintained per the Procedure for Distribution Records to support traceability and recall capability (minimum 10 years retention aligned with MDR).

## Sample batch protocol (summary)

For each production batch / release lot, records include as a minimum:

1. Purchase order references (RP Technologies; MPD; print suppliers as applicable)  
2. Shell lot identity and variant quantities (RS / RL / LS / LL)  
3. Soft-goods / assembly lot or work order reference (MPD)  
4. Incoming inspection results (pass/fail)  
5. Final release checklist and releaser name/date  
6. IFU version and carton artwork version used  
7. Quantity released and destination / stock location  

Detailed forms are held in the manufacturer’s quality records (not reproduced in full in this summary).

## Process controls and changes

- No silent substitution of material grade, geometry or critical textile components.  
- Supplier process, material or site changes require prior notification and Thetis Medical Ltd approval (see §3.4.3).  
- Design changes follow controlled drawing/BOM revision before the next production run.
