## 3.3 Description of quality control

Quality controls are applied at incoming, in-process and final stages. Acceptance criteria are pass/fail unless otherwise stated. Records are retained for a minimum of 10 years.

### 3.3.1 Incoming controls

| Check | Applies to | Acceptance criteria | Action if fail |
| ------- | ------------ | --------------------- | ---------------- |
| Identity / part match | Shells, foam, straps, fasteners, cartons, IFUs | Matches PO, drawing/revision and BOM (size, L/R, material) | Quarantine / reject / return to supplier |
| Visual defects | Shells | No cracks, short-shot, excessive flash, sharp edges; L/R deboss correct and legible | Reject lot or sort with concession record |
| Visual defects | Foam / straps / hook-and-loop | No contamination, fraying, wrong colour/width; OEKO-TEX / grade as specified | Reject / return |
| Labelling / print | Cartons, IFUs | Correct SKU text, language set, UDI/barcode as approved artwork | Quarantine; reprint |
| Certificates (as required) | Critical lots (e.g. PP, textiles) | TDS / CoC / cert available when requested for the grade used | Do not release until obtained or justified |

### 3.3.2 In-process controls (sewing / assembly)

| Check | Acceptance criteria |
| ------- | --------------------- |
| Foam attachment to shell | Fully secured along intended sew path; no loose edges that affect fit or safety |
| Strap attachment | Foot and leg straps fixed in correct positions / orientation; secure stitch |
| Ankle strap / heel aperture | Heel slit sized and positioned per approved sample; removable ankle strap attaches to shell patch |
| Guide features | Strap guide bumps / sewing groove used as designed; no assembly that blocks intended strap path |
| Cleanliness | No loose threads that could irritate skin; no foreign debris |

### 3.3.3 Final release controls (finished device)

Before packaging, each unit (or defined sampling plan for homogeneous lots) is checked for:

| Check | Acceptance criteria |
| ------- | --------------------- |
| Completeness | Shell + foam + leg strap + foot strap + ankle strap + patch present |
| Variant | Correct size (S/L) and side (L/R); matches carton label and UDI |
| Function | Straps fasten and release; ankle strap removable and re-attachable |
| Appearance | No sharp edges; no defects that could injure intact skin |
| IFU | Correct IFU version included in carton |
| Traceability | Lot / batch identity recorded for release |

**Release authority:** Guy Solan (or trained designee). Non-conforming product is quarantined; concessions require documented justification and do not override safety-critical failures.

### 3.3.4 Reactive quality control

Complaint handling and incident reporting (see QMS procedures) act as post-market quality feedback. Any complaint suggesting a manufacturing or design defect triggers investigation of the relevant lot and, where indicated, CAPA and risk-file update.

## 6.5 Stability, including shelf-life

### 6.5.1 Planning and overview

A formal accelerated ageing study (e.g. Arrhenius) was **not** performed. Shelf-life and in-use stability are justified by material properties, packaging, intended use duration, and field experience, proportionate to Class I risk.

### 6.5.2 Storage stability (shelf-life)

| Parameter | Justification |
| ----------- | ---------------- |
| Materials | Polypropylene shell, EVA foam, nylon/elastic textiles and hook-and-loop are stable under normal indoor warehouse/clinic/home conditions (ambient temperature and humidity; protected from UV and water) |
| Packaging | Primary packaging is a printed cardboard carton. Device is non-sterile and not fragile in normal handling; carton protects from dust and light during storage/transport |
| Degradation | No known time-dependent chemical instability of the finished assembly under recommended storage that would affect safety or plantarflexion performance within the claimed shelf-life |
| Field experience | Devices stored and shipped commercially since market launch without stability-related vigilance complaints |

**Claimed shelf-life:** **5 years** from date of manufacture when stored indoors in original packaging, away from direct sunlight, extreme heat, and moisture.

*(If you prefer a more conservative claim until you have formal ageing data, use **3 years** instead and keep the same rationale.)*

Manufacture / batch date (or equivalent lot coding) is controlled so that expired stock is not placed on the market.

### 6.5.3 Transport stability

Transport is by standard parcel/pallet logistics. The device is non-sterile and mechanically robust for normal shipping. Secondary packaging (outer cartons / pallets) protects primary cartons. No cold-chain or special humidity control is required. Transport-related damage is managed by incoming checks at distributor/customer and replacement under commercial terms; no transport-stability failures have been identified as a systemic safety issue in PMS.

### 6.5.4 In-use stability

| Parameter | Detail |
| ----------- | -------- |
| Intended in-use duration | Single-patient use over the ATR recovery window — typically up to ~10–12 weeks night/rest use |
| Duty cycle | Intermittent wear (primarily night / rest); not continuous weight-bearing |
| Cleaning | Wipe surfaces only (per IFU); no aggressive solvents or machine washing of the assembled device |
| Conclusion | Materials and construction remain fit for purpose for the intended in-use period. Negligible performance deterioration expected in normal use. Patients are instructed not to use a damaged device and to seek advice if unusual skin reaction occurs |

### 6.5.5 Maintenance and servicing

No scheduled servicing. Single-patient device for the recovery episode. Not refurbished for another patient.

### 6.5.6 Evaluation

Shelf-life and in-use stability are acceptable for the intended purpose. Residual risk of using a damaged or aged device is controlled by packaging, IFU, and complaint/vigilance processes. Formal real-time / accelerated ageing may be added later if market or notified-body expectations require quantitative data; current justification is risk-based and supported by materials knowledge and PMS.

### ITALIANO

**PRIMA DI UTILIZZARE IL TUTORE, LEGGERE ATTENTAMENTE LE SEGUENTI ISTRUZIONI PER GARANTIRE UN POSIZIONAMENTO CORRETTO E SICURO.**

**USO PREVISTO:** Tutore notturno per mantenere il piede in flessione plantare (piede rivolto verso il basso) nei primi 3 mesi dopo una rottura del tendine di Achille.

**COME UTILIZZARLO:**

1. Staccare completamente la cinghia centrale dal tutore.  
2. Posizionare il tutore sulla parte inferiore della tibia in modo che copra anche il dorso del piede. La schiuma all’estremità inferiore del tutore deve trovarsi appena sopra le articolazioni tra le dita e il piede.  
3. Avvolgere la cinghia superiore intorno alla parte posteriore del polpaccio inferiore e fissarla su se stessa con il Velcro.  
4. Avvolgere la cinghia inferiore sotto il piede e fissarla su se stessa con il Velcro.  
5. Inserire il tallone nell’apertura della cinghia centrale. Un’estremità si fissa con il Velcro sulla parte anteriore del tutore e l’altra estremità sulla cinghia stessa.

**AVVERTENZA:** Non restare in piedi né camminare con il tutore senza stampelle. Non è progettato per essere indossato durante la deambulazione, nemmeno in punta di piedi. Un uso improprio del tutore può causare una nuova lesione del tendine di Achille in fase di guarigione.

**PULIZIA:** Pulire solo le superfici con un panno.

**CONTROINDICAZIONI:** Utilizzare solo dopo le prime due settimane dalla rottura del tendine di Achille o secondo le indicazioni dello specialista.

**PRECAUZIONI:** Se le cinghie sono troppo strette possono comparire formicolio o dolore. Allentare le cinghie di solito risolve il problema. In caso di insolita discolorazione della pelle, gonfiore o disagio, consultare un medico.

Solo per uso su un singolo paziente.

SEBBENE SIA STATO FATTO OGNI SFORZO PER GARANTIRE FUNZIONE E COMFORT, L’USO DI QUESTO TUTORE NON GARANTISCE LA PREVENZIONE DI ULTERIORI LESIONI.
